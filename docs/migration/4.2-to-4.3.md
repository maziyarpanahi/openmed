# Migrating from 4.2 to 4.3

## Deprecated

### Free-form span evidence

The span JSON Schema and the web kit mark `OpenMedSpan.evidence` as deprecated.
Existing producers can still serialize arbitrary evidence keys. Consumers
should retain unknown keys when round-tripping existing 4.x spans.

The planned 5.0 representation uses typed evidence references. Continue
sending the 4.x object while the canonical reference schema and Python
accessor are being defined. Application-specific fields can move to
`OpenMedSpan.metadata` when their producers and consumers agree on the keys.
